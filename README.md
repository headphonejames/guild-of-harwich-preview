# Guild of Harwich Artists — Astro preview

Public-content preview built with Astro. Original public source: https://guildofharwichartists.org/.

This release includes independently stored public content and media. Historical biographies and event schedules are qualified; the archive preserves original wording. Unavailable source downloads are labeled. Historical image-size options point to archived originals. Source URLs and identifiers are retained for attribution.

## Build

Use Node >=22.23.4, then run `npm ci`, `npm run check`, and `npm run build`.

The existing GitHub Actions workflow builds and deploys approved pushes to main. This repository contains published/public historical content only. Local editorial drafts, the editing interface, authentication configuration, private exports and migration evidence are maintained separately and must not be committed here.

This is a design and migration preview, not the production Guild website. No forms, member authentication or purchases are processed. Contact information and historical notices came from the public source and may need reconfirmation. Artwork remains copyright its respective creators.
